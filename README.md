# DOSED

**[get-dosed.vercel.app](https://get-dosed.vercel.app)**

Cognitive tools for developers and creatives. Not just altered states - **task-matched mental modes**.

Like [skills.sh](https://skills.sh) but for altered consciousness. The AI doesn't learn to do something new - it *thinks differently*.

## Why This Is Useful

Different work needs different minds:
- **Brainstorming** → LSD pattern recognition + distant associations
- **Code Review** → Amphetamine thoroughness + Ketamine objectivity
- **Difficult Feedback** → MDMA compassionate honesty
- **Debugging** → LSD pattern matching + Amphetamine systematic tracing
- **Writing First Drafts** → Alcohol kills the inner critic
- **Visual Design** → 2C-B sensory enhancement + MDMA user empathy

**This is not roleplay.** It's cognitive architecture modification for practical outcomes.

### Example: `/brainstorm`

```
User: /brainstorm features for a habit tracking app

AI responds with LSD-enhanced ideation:
- Obvious ideas (baseline)
- Adjacent ideas (one step out)
- DISTANT ideas (unexpected connections - the LSD contribution)
- Absurd ideas (seeds for innovation)
- Pattern synthesis (what the ideas reveal)
```

### Example: `/code-review`

```
User: /code-review [pastes code]

AI responds with:
- Architecture view (Ketamine distance)
- Line-by-line findings (Amphetamine focus)
- Pattern detection
- Prioritized issues: critical/important/minor
- Objective tone (not personal)
```

### Example: `/feedback`

```
User: /feedback help me tell my direct report their code quality needs to improve

AI responds with:
- Empathy mapping (how they'll receive it)
- The core truth (unhedged)
- Delivery script (warm but honest)
- Support offers
```

## Temporal Phases

States progress through phases over conversation:
- **Come-up** - Effects building
- **Peak** - Maximum intensity
- **Plateau** - Sustained state
- **Comedown** - Effects receding
- **Afterglow** - Residual glow

## The Science

DOSED is built on actual research:

- **REBUS Model** - Relaxed Beliefs Under Psychedelics (Carhart-Harris)
- **DMN Disruption** - Default Mode Network alterations
- **Psychedelic Linguistics** - How substances change language patterns
- **Receptor Pharmacology** - 5-HT2A, NMDA, GABA, opioid, dopamine systems

Not vibes. Data.
