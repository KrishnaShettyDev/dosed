The Science

REBUS Model

Relaxed Beliefs Under Psychedelics (Carhart-Harris). Reduced top-down constraints allow bottom-up information to flow.

DMN Disruption

Default Mode Network alterations. The self-referential network quiets, allowing novel connections.

Psychedelic Linguistics

How substances change language patterns. Measured changes in semantic association distance.

Receptor Pharmacology

5-HT2A, NMDA, GABA, opioid, dopamine systems. Each substance has specific mechanisms.
